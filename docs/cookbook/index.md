## How to Use These Recipes

There are three ways to use any recipe in this cookbook:

### 1. Interactive Chat (Zero Setup)
Copy the prompt text directly into your BojuBot chat panel. Many recipes operate directly on your currently active note without needing any configuration.

### 2. Turn It into a Reusable Skill
Save the recipe as a `.md` file in your skills folder (default: `_BojuBot Skills/` or `.BojuBot/skills/`). It will immediately appear in your `/` slash menu and (optionally) in the Obsidian Command Palette.

```markdown
---
category: Reviews
description: Clean up today's daily note and roll forward tasks
autorun: true
---
[Prompt body goes here]
```

### 3. Ask BojuBot to Install It For You
Because BojuBot is an agent with vault access, you don't have to copy and paste files manually. Simply open the chat panel and say:

> *"Install the Nightly Sweep recipe from the cookbook into my skills folder."*

BojuBot will inspect your vault structure, customize the prompt to match your folder conventions, and write the `.md` file directly into your skills folder.

## Supplying Context to Recipes

Recipes achieve their best results when given the right context. BojuBot provides three seamless ways to feed context to a recipe:

| Method | When to Use | How to Do It |
| :--- | :--- | :--- |
| **Active Note** | Running a recipe on the file you currently have open in Obsidian. | BojuBot automatically detects your active note tab. Just run the skill. |
| **Selection Context** | Running a recipe on a specific paragraph, quote, or section. | Highlight text → press `Ctrl+P` → select **`BojuBot: Send selection as context`** (or bind it to `Alt+S`). |
| **@-Mention** | Pointing a recipe at notes other than the currently active one. | Type `@` in the chat box to fuzzy-search and attach notes or files as context badges. |

## Standard Recipe Schema

Every recipe in this cookbook strictly adheres to a consistent schema inspired by the classic O'Reilly cookbooks. If an element does not apply to a specific recipe, it is explicitly marked `None` so you always know what is needed:

| Schema Element | Description |
| :--- | :--- |
| **Difficulty** | 🟢 **Beginner** (Zero config / Active note) · 🟡 **Intermediate** (Plugins / Vault structure) · 🔴 **Advanced** (CLI binaries / Full Access) |
| **Problem** | The specific friction or operational pain point. |
| **Solution** | How BojuBot resolves it. |
| **Prerequisites** | External CLIs, binaries, or community plugins required (`None` if zero-dependency). |
| **Permission Level** | `Standard` (safe vault file tools) vs `Full Access / Shell` (command execution). |
| **Context Workflow** | How context is provided (`Active Note`, selection via `Alt+S`, `@-mention`, or `None`). |
| **Recipe / Skill** | The copyable prompt or complete `.md` skill file. May include **Alternatives** for different setups. |
| **Discussion & Nuances** | Technical details, protocol mechanics, and callout tips for vault customization. |
| **See Also** | Related recipes, skills, or reference documentation (`None` if standalone). |
